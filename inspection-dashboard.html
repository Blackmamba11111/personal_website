数据范围

用户管理

—

本地用户的口令存在本站（加盐哈希）；远程用户的口令由 RADIUS / TACACS+ / LDAP 服务器校验，本站不保存其密码。 「只读」账号可以查看与导出数据，但不能新增、修改、删除台账内容。

认证服务器

—

远程用户登录时，本站把用户名与密码转发给这里配置的服务器校验，校验通过后在本站签发会话。 共享密钥只保存在服务端，列表里不会回显；编辑时留空表示「不修改」。

数据日志

—

记录台账内容的变化（客户 / 巡检 / 区域的增删改，含字段级明细）；共享数据集的成员共用同一份历史。 操作人一列显示实际修改的账号；每次保存合并为一条记录。

客户管理

—

本页只维护客户基本资料，不含巡检记录；巡检完成情况请回看板在地图与客户卡片中查看。 删除客户会同时清掉该客户的巡检记录，操作不可恢复。所有改动实时同步到服务端对应账号的台账。

新建用户

仅支持字母、数字、下划线、点与连字符，长度 3–32 位。
登录时把用户名与密码转发给该服务器校验，本站不保存密码。
该用户首次登录后建议自行修改密码。
不复制数据：新用户与该用户共用同一份台账，任何一方的新增/修改/删除双方即时同步（刷新或切回页面后可见）。
仅在新建用户时生效。

新增认证服务器

与服务端设备上配置的一致；编辑时留空表示不修改。
用 {user} 代表登录名。AD 可直接填 {user}@corp.local 或 DOMAIN\{user}； 留空则把登录名本身当作绑定 DN。
目录不允许直接绑定用户 DN 时填写服务账号：先用服务账号在 Base DN 下按「用户属性=登录名」搜索用户， 再用用户口令绑定。Bind 密码只存服务端、不回显，编辑时留空表示不修改。
会真实发起一次认证请求，用于验证地址、端口与密钥是否正确。
